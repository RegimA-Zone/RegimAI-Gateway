# RegimAI ❤️ SkinTwin

## [ECAN Attention Allocation lab](ecan-attention-allocation.ipynb)

[![flow](../../images/ecan-attention-allocation.gif)](ecan-attention-allocation.ipynb)

Economic Attention Network (ECAN) for cognitive resource management across the SkinTwin architecture. This lab demonstrates how short-term importance (STI) and long-term importance (LTI) values are used to dynamically allocate attention budgets across cognitive architecture components such as PLN reasoning, AtomSpace, MOSES optimization, and ESN prediction.

[View policy configuration](ecan-policy.xml)

### Prerequisites

- [Python 3.12 or later version](https://www.python.org/) installed
- [VS Code](https://code.visualstudio.com/) installed with the [Jupyter notebook extension](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter) enabled
- [Python environment](https://code.visualstudio.com/docs/python/environments#_creating-environments) with the [requirements.txt](../../requirements.txt) or run `pip install -r requirements.txt` in your terminal
- [An Azure Subscription](https://azure.microsoft.com/free/) with [Contributor](https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles/privileged#contributor) + [RBAC Administrator](https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles/privileged#role-based-access-control-administrator) or [Owner](https://learn.microsoft.com/en-us/azure/role-based-access-control/built-in-roles/privileged#owner) roles
- [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli) installed and [Signed into your Azure subscription](https://learn.microsoft.com/cli/azure/authenticate-azure-cli-interactively)

### 🚀 Get started

Proceed by opening the [Jupyter notebook](ecan-attention-allocation.ipynb), and follow the steps provided.
